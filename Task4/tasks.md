# Задачи по ADR для дорожной карты

Источники - [ADR открытия депозитов онлайн](../Task3/ADR.md) и [ADR передачи ставок в кол-центры](ADR_2.md).

## MVP до 6 месяцев

| Код | Система или команда | Задача и результат | Зависимости |
| --- | --- | --- | --- |
| ABS-1 | АБС, Delphi и Oracle | Организовать ведение публичного каталога, актуальных и персональных ставок в АБС. Дать кредитному бэк-офису возможность сохранять ставки. | - |
| ABS-2 | АБС, Delphi и Oracle | Доработать рабочее место депозитного бэк-офиса и PL/SQL. Регистрировать онлайн-заявки с защитой от дублей по идентификатору. Подтверждать условия и открывать депозит, фиксируя отдельные события для СМС. | - |
| SMS-1 | СМС-шлюз и управление IT | Подтвердить протокол и настроить доступ депозитного сервиса и интеграционного сервиса АБС к шлюзу. Проверить доставку кода и обоих уведомлений. | - |
| KAFKA-1 | Kafka и управление IT | Развернуть Kafka и настроить потоки заявок, ставок для интернет-банка и отдельный топик публичных ставок для кол-центра. Настроить права, шифрование, мониторинг задержек и ошибок. | - |
| MAIL-1 | Почтовый шлюз банка | Согласовать адрес партнера, формат вложения и SMTP с TLS. Настроить доставку и проверить прием тестового письма. | - |
| CC-1 | Система кол-центра банка | Принимать и показывать операторам заявки с сайта. Подготовить сценарий обратного звонка, предложения особых условий и приглашения нового клиента в отделение. | - |
| ABS-3 | АБС, Delphi и Oracle | Реализовать запрос, сохранение и чтение результата оценки риска для специальной ставки. Разграничить права двух бэк-офисов, показывать статус и время оценки. | ABS-2 |
| INT-1 | Интеграционный сервис АБС | Принимать подтвержденные заявки из Kafka и регистрировать их через PL/SQL. Ограничивать скорость обработки с учетом нагрузки Oracle. | ABS-2, KAFKA-1 |
| INT-2 | Интеграционный сервис АБС | Читать опубликованный каталог из Oracle, публиковать актуальные и персональные ставки для интернет-банка и предоставить сайту HTTPS-интерфейс публичного каталога. | ABS-1, KAFKA-1 |
| INT-3 | Интеграционный сервис АБС | Прочитать отдельные события подтверждения ставки и открытия депозита и инициировать по ним два СМС-уведомления. Настроить повторные попытки при временных сбоях. | ABS-2, SMS-1 |
| INT-4 | Интеграционный сервис АБС | Публиковать каждую новую версию публичного каталога в топик кол-центра. Передавать номер версии и дату начала действия. | ABS-1, KAFKA-1 |
| INT-5 | Интеграционный сервис АБС | Формировать Excel-файл из той же версии публичных ставок и отправлять его партнеру через почтовый шлюз. Фиксировать результаты попыток публикации и отправки, повторять временные ошибки и оповещать сопровождение о задержках. | ABS-1, MAIL-1 |
| WEB-1 | Сайт банка | Показать публичный каталог и актуальные ставки. Добавить форму заявки с Ф. И. О. и телефоном и отправку заявки в систему кол-центра по HTTPS. Применить дизайн-систему банка. | INT-2, CC-1 |
| DEP-1 | Депозитный сервис и MS SQL | Принимать заявки и проверять СМС-код. Перед ответом об успешном подтверждении одной транзакцией сохранять заявку и запись для публикации. Отправлять ее в Kafka из фонового обработчика и повторять отправку при временных сбоях. | SMS-1, KAFKA-1 |
| DEP-2 | Депозитный сервис и MS SQL | Получать из Kafka каталог, актуальные и персональные ставки, обновлять локальную копию и выдавать данные веб-приложению. Ограничить выдачу персональных ставок данными аутентифицированного клиента. | INT-2, KAFKA-1 |
| IB-1 | Веб-приложение интернет-банка | Добавить просмотр каталога, актуальных и персональных ставок, выбор счета и суммы, отправку заявки и ввод СМС-кода. Интегрировать интерфейс с депозитным сервисом по HTTPS и применить дизайн-систему. | DEP-1, DEP-2 |
| CC-2 | Система кол-центра банка и PostgreSQL | Читать публичный топик Kafka, проверять версии и обновлять локальный каталог. Показывать оператору ставки, дату действия и признак неподтвержденной актуальности. | INT-4, KAFKA-1 |
| PART-1 | Партнерский кол-центр | Организовать прием файла, проверку версии, публикацию для операторов и подтверждение обновления. | MAIL-1, INT-5 |
| TEL-1 | Маршрутизатор звонков и оба кол-центра | Настроить перенаправление партнеру и определить действия при его недоступности. | PART-1 для включения маршрута |
| BR-1 | Сеть отделений | Подготовить процесс личной идентификации нового клиента после звонка по заявке с сайта и дальнейшего оформления депозита. | CC-1 |
| OPS-1 | Инфраструктура и сопровождение | Подготовить горизонтальное масштабирование веб-приложения и депозитного сервиса, резервный ЦОД, переключение трафика, восстановление записи в MS SQL и доступ к Kafka и СМС-шлюзу. | KAFKA-1, SMS-1 |
